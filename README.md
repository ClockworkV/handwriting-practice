# Handwriting Practice

Make printable A4 handwriting worksheets with a model, dotted or dashed tracing,
and space to practise. Choose a handwriting font, size and page orientation.
Add a second page if you want room to write the passage twice without guides.

## Open locally

Open `index.html` in a browser. Keep it next to the other app files.

## Publish on GitHub Pages

Push this repository to GitHub. In **Settings → Pages**, choose **Deploy from
a branch**, select **main** and **/ (root)**, and save. The app is served from
the repository's Pages URL.
